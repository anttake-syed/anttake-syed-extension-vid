## How to Capture Screenshots

1. Open any `.html` file in Chrome
2. Set browser zoom to **100%**
3. The canvas is exactly **1280 × 800 px** — use DevTools device toolbar or a screenshot tool
4. Save as PNG into this folder with the matching filename

## Chrome Web Store Requirements

- **5 screenshots**: 1280 × 800 px or 640 × 400 px
- **Small promo tile**: 440 × 280 px
- **Large promo tile**: 1400 × 560 px (marquee)
